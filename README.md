⚡ Algorithm Performance Analysis

Benchmarking sorting and searching algorithms across five programming languages

This project explores how algorithm performance changes with input size, algorithm choice, and programming language. Multiple sorting and searching algorithms were implemented, benchmarked, and compared using measured runtime data.

📌 Project Overview

The goal of this project was to evaluate the practical performance of common algorithms rather than relying solely on theoretical complexity.

Benchmark tests were performed across:

☕ Java
🐍 Python
⚡ C++
🔷 C#
🟨 JavaScript

Different input sizes were used to measure runtime performance and identify trends between algorithms and languages.

🎯 Objectives

Implement sorting and searching algorithms in five programming languages
Benchmark algorithm runtime across different input sizes
Collect and analyze performance data
Compare algorithm efficiency using experimental results
Visualize benchmark results and performance trends
Examine how programming language affects practical runtime
